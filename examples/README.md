# Examples (synthetic)

Everything in this folder is made up. The people, firms, deals and messages do not exist. The formats are the real ones the routines write: one brief per slot, one alert file per alert, one log line per run, one markdown file per outbox draft.

- `briefs/2026-11-04/0800.md`: a morning brief
- `briefs/2026-11-04/alert-1610.md`: the one alert the watcher raised that day
- `briefs/2026-11-04/1800.md`: the evening brief
- `log/2026-11.md`: a day of log lines, mostly silent watcher passes
- `outbox/2026-11-04/lark-diligence-call.md`: a draft waiting for the owner
