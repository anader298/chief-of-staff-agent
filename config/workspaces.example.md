# Workspaces and where files live (EXAMPLE)

| Workspace | Folder | Covers |
|---|---|---|
| work | ~/work | the day job: deals, models, memos |
| racing | ~/racing | partnerships, team mail, event logistics |
| personal | ~/personal | admin, finance, applications |
| general | ~/general | everything else, including this repo |

Cloud routines do not see these paths. They see this repo plus whatever connectors are attached (mail, calendar, drive). When a brief needs a local file, say which one and the owner or an interactive session fetches it.
